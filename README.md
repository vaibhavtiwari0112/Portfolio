# Vaibhav Tiwari – Portfolio
Static site (HTML, CSS, JS). No build step.

## Deploy to Vercel
1. Push this folder to a GitHub repo, then import it at vercel.com/new (Framework: Other, no build command, output directory: `.`).
2. Or run `npx vercel --prod` inside this folder.

## Before sharing
Replace the LinkedIn and GitHub URLs in `index.html` (ids: `li`, `gh`, `gh-project`).
